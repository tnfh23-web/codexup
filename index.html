      Library 파일·폴더 공유

      발표일
      2026-09-09
      공유 기능
      ChatGPT Library의 파일과 폴더를 특정 사람에게 공유하고 Viewer 또는 Editor 권한을 지정할 수 있습니다. 워크스페이스 전체에 공개하거나, 공유 대화상자에서 접근 권한을 변경·회수하는 것도 가능합니다.
      공유 콘텐츠 사용
      다른 사람이 공유한 자료는 ‘Shared with me’에서 찾고 ChatGPT 대화에 바로 활용할 수 있습니다.
      소유권
      공유 폴더에 올린 파일은 폴더 소유자에게 귀속되며 업로드한 사람의 기록은 남습니다. 다른 사람의 공유 폴더에 파일을 올린 뒤 접근 권한을 잃으면 파일은 그 폴더에 남고 업로더는 더 이상 접근할 수 없습니다.
      사용자 영향
      자료를 다시 내려받아 전달하지 않아도 ChatGPT 안에서 공동 파일을 관리하고 대화에 활용할 수 있습니다. 다른 사람의 폴더에 올리는 파일은 소유권과 접근 권한이 달라질 수 있으므로 주의가 필요합니다.

      공식 출처ChatGPT 릴리스 노트

      한눈에 보기

      GPT-6 Astra 도입과 플러그인·Sites 공유 확대

      발표일
      2026-09-03
      GPT-6 Astra
      코딩, 조사, 컴퓨터 사용과 여러 단계의 복잡한 작업을 개선한 GPT-6 Astra가 제한된 일부 조직부터 순차적으로 제공됩니다. 문서·스프레드시트·프레젠테이션을 템플릿과 지시에 맞춰 만들고, 작업 중 요구사항이 바뀌어도 대응할 수 있습니다.
      안전 확인
      Astra에는 에이전트가 사용자의 지시를 잘못 이해했을 가능성을 살피는 추가 안전 모니터링이 포함됩니다. 문제가 의심되면 대화가 잠시 멈추거나 종료돼 사용자가 검토하고 진행 여부를 선택할 수 있습니다.
      새 플러그인
      Zendesk와 OneNote 플러그인이 베타로 추가됐습니다. 고객 지원 기록을 살펴 답변을 준비하거나, 노트에서 결정 사항과 할 일을 찾아 요약하고 지원되는 작업으로 노트를 갱신할 수 있습니다.
      Sites 공유
      대상 Site 소유자는 사이트를 공개하지 않고도 워크스페이스 밖의 지정된 사람에게 뷰어 권한을 줄 수 있습니다. 초대받은 사람은 사이트를 사용할 수 있지만 편집하거나 게시할 수는 없습니다.
      사용자 영향
      Astra는 아직 일반 공개가 아니라 계정에 순차 적용됩니다. 사용 가능해지면 복합 작업의 완성도와 방향 수정 대응이 좋아지고, 조직에서는 고객 지원·노트 업무와 비공개 외부 사이트 공유 범위가 넓어집니다.

      한눈에 보기

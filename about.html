02 / HOW IT WORKS

매일 9시 40분,
자동으로 확인합니다.

주말에 놓친 소식은 월요일 실행에서 함께 확인합니다.

  1. TRIGGER

    예약 실행

    컴퓨터가 켜져 있는 평일 오전 9시 40분에 확인 작업을 시작합니다.

  2. VERIFY

    공식 자료 비교

    ChatGPT 릴리스 노트, Codex changelog와 GitHub 정식 릴리스를 대조합니다.

  3. TRANSLATE

    사용자 언어로 정리

    발표일·핵심 변경·사용자 영향을 한국어로 풀고 ‘한눈에 보기’를 덧붙입니다.

  4. PUBLISH

    웹 아카이브에 기록

    검증한 내용을 탐색하기 쉬운 HTML 카드로 추가해 한곳에서 관리합니다.
